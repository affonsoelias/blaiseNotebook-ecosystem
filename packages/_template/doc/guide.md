# 📖 Package Guide: _template

This directory is an **optional documentation folder** for storing detailed technical documentation, tutorials, and specifications written in Markdown (`.md`).

## Documentation Guidelines

* Keep your quick-start guide in `README.md` at the package root.
* Place in-depth guides, architectural references, or multi-chapter documentation inside this `doc/` directory:
  * `doc/guide.md`
  * `doc/api-reference.md`
  * `doc/troubleshooting.md`
