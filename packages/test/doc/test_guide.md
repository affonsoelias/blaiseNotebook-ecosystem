# 📖 Test Package Documentation

This document demonstrates the **optional `doc/` directory** for ecosystem packages.

## Overview
The `test` package verifies that the BlaiseNotebook package resolution, compiler include paths, and runtime execution work seamlessly across Windows, Linux, and macOS.

## Unit API
* `uTestPackageInfo`: Returns validation banner and version.
* `uTestPackageAdd(A, B)`: Simple arithmetic sum used for assertion tests in notebooks.
